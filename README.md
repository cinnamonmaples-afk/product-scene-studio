# 造景 · 商品影像工作室

中文商品场景图生成器，使用 Gemini 与火山方舟豆包官方 API。上传一张或多张产品参考图，选择风格和比例，创建可编辑场景，生成样图或批量图片。支持单张重做、历史系列复用、ZIP 下载。

## 运行

Node.js 22.13+，npm ci，npm run dev。生产使用 Cloudflare Workers、D1、R2。数据库结构位于 db/schema.ts，迁移位于 drizzle。导出版本不包含登录模块，使用单一工作区。

配置 CREDENTIAL_ENCRYPTION_KEY 为随机 32 字节的 Base64 值。用户在应用中填写各服务商的 API Key，分别保存，使用 AES-GCM 加密存入 D1。生产密钥通过托管环境配置，不写入源码。

## 使用边界

每个系列 1–100 张，逐张请求，服务商错误时暂停队列。上传数量不人为限制，浏览器将图片缩至最长边 1600 像素，每张上传不超过 2 MB。每个任务选择主参考图与最多三张补充参考，样图可额外作为风格参考。默认输出为 2K。支持 Gemini Image 与 Doubao Seedream 5.0 Pro；gemini-3.8-flash 不支持图片生成。临时限流按服务商建议等待，零配额或每日额度耗尽不自动重试。

生成时保持页面打开；关闭后已保存结果不丢失，未完成任务可从历史记录恢复。十分钟未完成的请求显示为失败，允许人工重试。模型不保证商品细节完全一致，使用前应检查。
